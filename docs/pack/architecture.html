System overview

Red paths are refusals. Three of the five decision points in the AI layer can decline to produce a result.

The feedback loop is the part most systems lack. Confirmed outcomes are recorded against the prediction that was made, so this deployment can compute its own performance rather than quoting the vendor's held-out figure. That is what a procurement decision and a SAHPRA post-market surveillance plan both require, and it was built before there was anything to measure.

Security and data protection

ControlImplementation
Encryption at restAES-GCM under a rotatable keyring; key ids in the ciphertext envelope so rotation is possible without data loss. Clinical free text, contact details, MFA secrets.
Access controlCare relationships derived from appointments and scan assignments; time-boxed break-glass with written justification, high-severity audit and administrator notification.
Second factorTOTP with single-use recovery codes; secret encrypted at rest.
AuditAppend-only, non-identifying detail, 34 audited operations; separate genomic access log.
Cross-border (POPIA §72)Redacted before transmission, consent checked per message, versioned disclosure, transfer log recording categories not values.
Data subject rightsErasure adjudicated per category against the six-year health-record retention duty; the outcome names the instrument.

Two controls ship in shadow mode. MFA_ENFORCE and CARE_RELATIONSHIP_ENFORCE both default off, so existing clinicians are not locked out mid-deploy. The care check still runs and records what it would have refused, so the derivation can be measured before it starts denying access. Code that can enforce a control is not the same as a control being enforced, and the DPIA marks both as mitigated-in-shadow rather than closed.

Deployment

ServiceNotes
Web (Node/Express)Refuses to start in production without a session secret, TLS, and durable object storage for scan images.
Inference (FastAPI, private)Both models resident. Private service: nothing outside the cluster submits an image, and it has no authentication of its own by design — it is reached only by the web service, which has already authorised the request and checked consent.
PostgreSQLSessions, clinical records, audit. Bounded connection pool sized to the pooler's own limit.
Object storagePrivate; reads only via an authorised, audited endpoint issuing 10-minute signed URLs.

Known blocking limitation. The lung model refuses clinical DICOM. The pipeline around it — ingest, de-identify, window, screen, classify, review — is complete and tested; the model at the end of it was trained on web-sourced images and declines every real acquisition. Retraining on a documented CT dataset with patient-level splits is the first item of clinical work, not a later refinement. Recorded in the model card rather than left to be discovered.
